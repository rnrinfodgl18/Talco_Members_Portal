User Manual · பயனர் கையேடு

For members and TALCO office users · உறுப்பினர்கள் மற்றும் TALCO office users பயன்பாட்டிற்கு

1. Sign in / உள்நுழைவு

Enter your registered email and password. Use Forgot password when required.
பதிவு செய்யப்பட்ட email மற்றும் password-ஐ உள்ளிடவும். Password மறந்தால் Forgot password பயன்படுத்தவும்.

2. Dashboard / முகப்புப் பக்கம்

View closing balance, unread notices and shortcuts. Tap My Ledgers for account details.
Closing balance, புதிய notices மற்றும் shortcuts பார்க்கலாம். Account details-க்கு My Ledgers அழுத்தவும்.

3. Ledger / லெட்ஜர்

Select the account and open Statement, All bills or All payments. Red Dr is amount due. Green Cr is advance/credit. Use Print / Save PDF for a formal copy.
Account-ஐ தேர்வு செய்து Statement, All bills அல்லது All payments பார்க்கவும். சிவப்பு Dr செலுத்த வேண்டிய தொகை. பச்சை Cr advance/credit. Formal copy-க்கு Print / Save PDF பயன்படுத்தவும்.

4. Bills & receipts / பில்கள் மற்றும் ரசீதுகள்

Open a bill with View and download the official PDF. All payments lists posted receipts. Report incorrect entries to the office.
View மூலம் bill-ஐ திறந்து official PDF download செய்யலாம். All payments-ல் receipts தெரியும். தவறான entry-ஐ office-க்கு தெரிவிக்கவும்.

5. Notices / அறிவிப்புகள்

Use Notice Board or the bell icon for circulars and updates.
Circulars மற்றும் updates பார்க்க Notice Board அல்லது bell icon பயன்படுத்தவும்.

6. Profile / சுயவிவரம்

Update name, phone and notification choices in Settings. Verify email for official messages.
பெயர், phone, notification விருப்பங்களை Settings-ல் update செய்து email-ஐ verify செய்யவும்.

7. Install as mobile app / மொபைல் app-ஆக நிறுவுதல்

In Chrome or Edge choose Install app / Add to Home screen. Open TALCO from the phone home screen and allow notifications.
Chrome அல்லது Edge-ல் Install app / Add to Home screen தேர்வு செய்யவும். Home screen-ல் TALCO-ஐ திறந்து notifications-ஐ Allow செய்யவும்.
Security / பாதுகாப்பு: Never share your password or OTP. Password அல்லது OTP-ஐ யாரிடமும் பகிர வேண்டாம்.
