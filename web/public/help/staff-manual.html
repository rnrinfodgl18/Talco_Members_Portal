TALCO Office User / Staff Manual

Daily operating instructions · தினசரி பயன்பாட்டு வழிகாட்டி

For: TALCO accounts and office staff · Purpose: imports, mapping and member service

1. Start the day / தினசரி தொடக்கம்

Sign in and check Dashboard cards, recent imports, notices and pending mapping. Confirm you are working in the correct month before uploading.
Login செய்து Dashboard cards, recent imports, notices மற்றும் pending mapping பார்க்கவும். Upload செய்வதற்கு முன் சரியான மாதமா என்று உறுதி செய்யவும்.

2. Prepare files / Files தயார் செய்தல்

Use the approved Sales/Bill or Receipt Excel template, or supported Tally XML. Keep party name, voucher/bill number, date and amount. Missing optional values may show a warning.
Approved Sales/Bill அல்லது Receipt Excel template, அல்லது supported Tally XML பயன்படுத்தவும். Party name, voucher/bill number, date, amount இருக்க வேண்டும். Optional data இல்லையெனில் warning வரும்.

3. Upload → Review → Post / Upload → Review → Post

Choose the file and period, then select Upload and review. Compare row count and gross total with the source report. Read warnings and duplicates. Post only after the totals match.
File மற்றும் period தேர்வு செய்து Upload and review அழுத்தவும். Source report-உடன் row count மற்றும் gross total ஒப்பிடவும். Warnings, duplicates பார்த்து total சரியாக இருந்தால் மட்டும் Post செய்யவும்.

4. Mapping Queue / Ledger mapping

For unmatched rows, open Mapping Queue and select the correct ledger/tannery. Check similar names carefully. If an existing binding is wrong, Unbind and bind again to the correct account.
Unmatched rows-க்கு Mapping Queue திறந்து சரியான ledger/tannery தேர்வு செய்யவும். ஒரே மாதிரி பெயர்களை கவனமாகச் சரிபார்க்கவும். Existing binding தவறாக இருந்தால் Unbind செய்து சரியாக மீண்டும் bind செய்யவும்.

5. Verify after posting / Posting பிறகு verification

Open Account Ledgers and verify the affected party's closing balance. Check All bills, All payments and invoice view. Use Print / Save PDF when a formal ledger copy is requested.
Account Ledgers-ல் சம்பந்தப்பட்ட party closing balance சரிபார்க்கவும். All bills, All payments மற்றும் invoice view பார்க்கவும். Formal ledger கேட்டால் Print / Save PDF பயன்படுத்தவும்.

6. Correct an error / தவறை சரிசெய்தல்

Do not upload another duplicate batch. Open the posted batch/record and use the approved correction or cancellation process with a reason. Ask the administrator when approval is required.
Duplicate batch மீண்டும் upload செய்ய வேண்டாம். Posted batch/record-ல் approved correction அல்லது cancellation process-ஐ reason உடன் பயன்படுத்தவும். Approval தேவையானால் admin-ஐ அணுகவும்.

7. Member assistance / Member உதவி

Guide members to My Ledgers, Notice Board, Settings and Help. Never ask for their password or OTP. Report email or notification failures with the member email and time of failure.
Members-க்கு My Ledgers, Notice Board, Settings மற்றும் Help பயன்படுத்த வழிகாட்டவும். Password அல்லது OTP கேட்க வேண்டாம். Email/notification failure-க்கு member email மற்றும் நேரத்தை பதிவு செய்யவும்.
Before posting / Post செய்வதற்கு முன்: File type ✓ Period ✓ Row count ✓ Gross total ✓ Duplicate check ✓ Mapping warnings ✓
