TALCO Admin Startup Manual

Administrator setup & control · நிர்வாக தொடக்க வழிகாட்டி

For: TALCO Administrator · Purpose: initial setup, control and verification

1. First login & company setup / முதல் login மற்றும் company setup

Sign in with the administrator account. Open Settings → Company Profile; confirm name, address, GSTIN, phone, email and logo. Configure SMTP and send a test email.
Admin account-ல் login செய்து Settings → Company Profile திறக்கவும். பெயர், முகவரி, GSTIN, phone, email, logo சரிபார்க்கவும். SMTP configure செய்து test email அனுப்பவும்.

2. Pump & Tannery Masters / Pump மற்றும் Tannery masters

Create Pump Master first. Then create or import Tannery Master and select the correct pump. Serial numbers are generated automatically. Check duplicate names before saving.
முதலில் Pump Master உருவாக்கவும். பிறகு சரியான pump-ஐ தேர்வு செய்து Tannery Master create/import செய்யவும். Serial number தானாக வரும். Duplicate பெயர் இல்லையா என்று பார்க்கவும்.

3. Ledger & opening balance / Ledger மற்றும் opening balance

Create ledger accounts and link the correct tannery relationship (owner/lessee). Enter opening balance manually or use Opening Balance Import. A second import shows changes and requires approval before overwrite.
Ledger account உருவாக்கி சரியான tannery relationship (owner/lessee) link செய்யவும். Opening balance manual-ஆக அல்லது import மூலம் சேர்க்கலாம். மறுபடியும் import செய்தால் changes காட்டப்பட்டு approval பெற்ற பிறகே overwrite ஆகும்.

4. Invite users / Users-ஐ invite செய்தல்

Open Users, enter the member/staff email, assign the correct role and ledger access, then send the invitation. The user sets a password from the email link. Verify email delivery and account access.
Users பகுதியில் email, சரியான role மற்றும் ledger access கொடுத்து invitation அனுப்பவும். Email link மூலம் user password set செய்வார். Mail delivery மற்றும் account access சரிபார்க்கவும்.

5. Monthly imports / மாதாந்திர imports

Upload Sales/Bills and Receipt Excel or Tally XML in Imports. Review row count, totals, warnings and duplicates before posting. Do not post the same period twice unless correcting an approved batch.
Imports பகுதியில் Sales/Bills மற்றும் Receipt Excel அல்லது Tally XML upload செய்யவும். Post செய்வதற்கு முன் rows, total, warnings, duplicates சரிபார்க்கவும். Approved correction இல்லாமல் ஒரே period-ஐ இரண்டு முறை post செய்ய வேண்டாம்.

6. Mapping & corrections / Mapping மற்றும் corrections

Resolve unmatched names in Mapping Queue. Bind the alias to the correct ledger/tannery. Use Unbind only for a wrong relationship; then remap it. Corrections and cancellations must include a clear reason.
Mapping Queue-ல் unmatched names-ஐ சரியான ledger/tannery-க்கு bind செய்யவும். தவறான link என்றால் மட்டும் Unbind செய்து remap செய்யவும். Correction/cancellation-க்கு தெளிவான reason அவசியம்.

7. Circulars & verification / Circulars மற்றும் verification

Publish notices with a clear title, date and attachment. Verify member visibility, ledger closing, bill PDF, receipt list and notification delivery after each monthly posting.
Title, date, attachment உடன் circular publish செய்யவும். ஒவ்வொரு monthly posting பிறகும் member view, ledger closing, bill PDF, receipts மற்றும் notifications சரிபார்க்கவும்.
Go-live checklist / தொடக்க checklist: Company profile ✓ Pumps ✓ Tanneries ✓ Ledgers ✓ Opening balances ✓ User invitations ✓ SMTP test ✓ Sample bill/receipt import ✓ Member login verification ✓
Important / முக்கியம்: Always review totals before Post/Approve. Never share the admin password or email OTP.
