TALCO Member Manual

Member portal instructions · உறுப்பினர் பயன்பாட்டு வழிகாட்டி

For: Tannery owners, lessees and authorised members

1. Invitation & password / Invitation மற்றும் password

Open the invitation link sent to your registered email. Confirm the displayed email, create a password and sign in. If the link expires, contact the TALCO office.
Registered email-க்கு வந்த invitation link-ஐ திறக்கவும். காட்டப்படும் email சரியா என்று பார்த்து password உருவாக்கி login செய்யவும். Link expire ஆனால் TALCO office-ஐ தொடர்பு கொள்ளவும்.

2. Dashboard / முகப்புப் பக்கம்

The dashboard shows total closing balance, unread notifications and your ledger accounts. Tap an account card to open it.
Dashboard-ல் total closing balance, unread notifications மற்றும் உங்கள் ledger accounts தெரியும். Account card-ஐ அழுத்தி திறக்கவும்.

3. Understand the balance / Balance புரிதல்

Red Dr means an amount is due. Green Cr means advance/credit is available. Opening balance and posted bills/payments determine the closing balance.
சிவப்பு Dr என்பது செலுத்த வேண்டிய தொகை. பச்சை Cr என்பது advance/credit. Opening balance மற்றும் posted bills/payments அடிப்படையில் closing balance கணக்கிடப்படும்.

4. Statement, bills & payments / Statement, bills மற்றும் payments

Use Statement for the running ledger, All bills for invoices and All payments for receipts. Tap View on a bill to see details and download the official PDF.
Running ledger-க்கு Statement, invoices-க்கு All bills, receipts-க்கு All payments பயன்படுத்தவும். Bill details மற்றும் official PDF-க்கு View அழுத்தவும்.

5. Print or save ledger / Ledger print அல்லது save

Open Statement and tap Print / Save PDF. On the phone print screen, choose Save as PDF to keep a copy or select a connected printer.
Statement திறந்து Print / Save PDF அழுத்தவும். Phone print screen-ல் Save as PDF தேர்வு செய்து copy சேமிக்கலாம் அல்லது printer தேர்வு செய்யலாம்.

6. Notices & profile / Notices மற்றும் profile

Use the bell or Notice Board for official circulars. Open Settings to update name, phone and notification choices. Complete email verification to receive messages.
Official circulars-க்கு bell அல்லது Notice Board பயன்படுத்தவும். பெயர், phone, notifications update செய்ய Settings திறக்கவும். Messages பெற email verification முடிக்கவும்.

7. Install on mobile / மொபைலில் install

Open TALCO in Chrome/Edge, choose Install app / Add to Home screen, then open it from the phone home screen. Allow notifications when asked.
Chrome/Edge-ல் TALCO திறந்து Install app / Add to Home screen தேர்வு செய்யவும். Phone Home screen-ல் இருந்து app-ஐ திறந்து notifications-ஐ Allow செய்யவும்.
When reporting a problem / பிரச்சனை தெரிவிக்கும்போது: Share account name, page name, date and screenshot. Do not include your password or OTP.
Security / பாதுகாப்பு: TALCO staff will not ask for your password or OTP. Logout when using a shared phone or computer.
